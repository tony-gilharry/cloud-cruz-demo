## Synthesis

**Recurring archetypes**

| Archetype | Vercel | Anthropic | Intuit | MongoDB | MS Fabric | Ramp |
|---|---|---|---|---|---|---|
| SI / consultancy / implementation | Yes | Yes (core) | Yes (IES) | Yes | Yes (core) | Yes |
| ISV / technology integration | Yes | Yes | Yes | Yes | Yes (workloads) | Yes |
| Built-on / powered-by / embedded | No (inferred) | Yes | No | Yes | Yes | Yes (Embedded) |
| Cloud marketplace | No | Yes | No | Yes | Is the marketplace | No |
| Agency (digital / web) | Yes (core) | Yes (named) | No | No | No | No |
| Accountants / bookkeepers | No | No | Yes (core) | No | No | Yes (core) |
| Reseller / VAR / CSP | Not public | No | Yes (IES) | Not public | Yes (CSP) | Yes |
| Referral-only / capital networks | Referral fund | No | Yes | No | No | Yes (VC, PE, franchise) |

Tier gates recur in three forms: certified-individual counts (Anthropic, Microsoft, Vercel, Intuit, MongoDB), production-customer or usage counts (Anthropic, Microsoft, Intuit apps, Ramp), and referral volume or dollars (Ramp, Intuit ProPartner).

**Overlap to note:** Cloud Cruz's current tier names (Member, Select, Premier, Elite) closely mirror Intuit ProPartner (Member ... Premier Partner, Elite Partner) and Anthropic's Services Track (Select, Global Premier).

**Candidate framings for what Cloud Cruz sells** (not ranked):
- **A. Developer and data platform.** Resonates with Vercel, MongoDB, Microsoft Fabric, Anthropic. Weak for Intuit and Ramp. Most standard, easiest to defend, most generic.
- **B. AI platform for finance teams.** Resonates with Ramp, Intuit, Anthropic; partial for Fabric. Weak for Vercel and MongoDB. Most distinctive (the accountant channel), pulls away from dev platforms.
- **C. AI data layer for business apps, embedded by ISVs and built on warehouses and ERPs.** Touches all six through ISV and SI archetypes; likely drops agencies or accountants as a core type; hardest to explain in one line.

Not public or uncertain: Vercel tier criteria, MongoDB tiers, Ramp referral economics beyond the bonus; Intuit App Partner thresholds are from a secondary source; Frontier Accelerate launch unconfirmed.
